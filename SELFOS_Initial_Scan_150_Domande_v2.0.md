## LEGENDA TIPI DI RISPOSTA
- **SCALA** = slider 1-10
- **SCELTA** = opzione multipla (scegli una)
- **MULTI** = opzione multipla (scegli tutte che si applicano)
- **FRASE** = completamento di frase (testo libero)
- **TESTO** = risposta aperta (testo libero)
- **ACCORDO** = scala 1-5 (1=per niente, 5=completamente)

## LEGENDA OPZIONI
- ✓ = opzione di espansione (sano, funzionale)
- ~ = opzione di inconsapevolezza (non ho ancora dati su questo)
- [nessun simbolo] = opzione di loop (pattern disfunzionale)
